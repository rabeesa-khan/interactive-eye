# 👁️ Interactive Cinematic Eye & Heart Experience

A hyper-realistic, modern, and cinematic interactive web application built with **HTML5 Canvas, CSS3, and Vanilla JavaScript**. It features a procedurally rendered human eye that tracks your cursor, reacts to touches, and triggers a smooth cinematic zoom into a romantic interactive heart animation.

---

## ✨ Key Features

- **Hyper-Realistic Eye & Sclera:** Procedurally generated micro-capillaries, radial iris fiber strands, dark limbal ring, and crisp corneal specular light reflections.
- **Organic Blinking & Tracking:** The eye naturally blinks at random intervals and smoothly tracks the user's cursor or touch position with fluid physics.
- **Cinematic Zoom Sequence:** Clicking/tapping directly on the pupil triggers a smooth cubic-bezier camera zoom into complete darkness.
- **Typography & Particle Reveal:** Smooth transition displaying glowing typography (*'I LOVE YOU'*) surrounded by floating bokeh light spheres and warm rose bloom effects.
- **Pulsing Heart & Shockwaves:** Transforms into a pulsing heart with a realistic double-beat heartbeat animation that responds to clicks with glowing pink shockwaves and spark particles.

---

## 🛠️ Built With

- **HTML5 Canvas API** — Real-time 2D procedural rendering, dynamic particle dynamics, and canvas lighting.
- **Vanilla JavaScript (ES6+)** — Trigonometry calculations, spring easing physics, and state management without external heavy libraries.
- **CSS3** — Clean, minimalist, modern responsive layout.
